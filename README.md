# Applicants System
### A C++ console application for managing and displaying applicant information using OOP.

## Features
- `clsPerson` class to represent a person.
- Store personal information:
  - First Name
  - Last Name
  - Age
  - Phone Number
  - Address
- Getters and Setters for accessing and modifying private data.
- Input validation for Age and Phone Number.
- Display personal information using an organized Information Card.
- Applicant acceptance evaluation based on age:
  - Accepted: 18 years or older.
  - Rejected: Under 18 years.
- Display different messages depending on the applicant's evaluation.

## Information Card
```
-------------------------------------
  First Name  : -
  Last Name   : -
  Full Name   : -
  Age         : -
  Phone Number: -
  Address     : -
-------------------------------------
```

## Technologies
- Language: C++
- Compiler: MSVC (Visual C++)
